## 🛠️ The Linter
Automated quality checker for SKILL.md files:
- ✅ Validates YAML frontmatter
- ✅ Detects security risks (rm -rf, sudo, etc.)
- ✅ Checks broken links
- ✅ Auto-fix mode (`--fix`)

## 🚀 How to Use

1. Download any skill
2. Run: `python3 skill_lint.py skills/[skill-name]`
3. Fix the errors
4. Use in your project!
